**better-duck** is a safe, embedded-first Rust client for [DuckDB](https://duckdb.org). The DuckDB
C library compiles straight into your binary — no system package, no runtime dependency — and every
FFI call is wrapped so nothing `unsafe` leaks into your code, across the full DuckDB type system.

## Highlights

- **Bundled DuckDB** — compiles from source; no system library to install.
- **Row-oriented, Arrow-optional** — a lean dependency tree for application-level OLAP, with an
  opt-in `arrow` feature that exports results via the Arrow C Data Interface with no added dependencies.
- **Safe by construction** — the whole DuckDB type system behind a safe API.
- **Comprehensive types** — every integer width, `DECIMAL`, `UUID`, `BIT`, `BIGNUM`, temporals, and
  the composite `LIST` / `ARRAY` / `STRUCT` / `MAP` / `UNION` / `ENUM` types.
- **Diesel 2.3 backend** — query DSL, migrations, an r2d2 pool, and a large library of DuckDB-specific
  SQL functions, aggregates, and operators.
- **UDFs & derives** — register plain Rust functions as scalar/table/aggregate/cast functions and map
  Rust structs/enums to DuckDB rows and types with `#[derive(…)]` — no `unsafe`, no manual vectors.
- **Embedded-first** — built to run inside Tauri desktop apps, iOS cross-builds, and anywhere a system
  library isn't an option.
